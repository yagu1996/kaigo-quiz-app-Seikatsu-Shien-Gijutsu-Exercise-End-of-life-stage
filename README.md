# 生活支援技術 第6章「人生の最終段階における介護」練習問題アプリ (v2)

介護福祉系の大学や専門学校の授業で活用できる、Streamlitベースの練習問題Webアプリケーションです。
端末のOS・ブラウザのダークモード設定に左右されず、常に高コントラストで視認性を保つ「固定テーマ設定（ライトモード固定）」を搭載しています。

---

## アプリの主な特長

1. **教科書準拠の全70問・4択問題演習**
   - 第6章「人生の最終段階における介護」の全範囲（全8テーマ）を網羅。
   - 即時判定と、現場未経験の学生にもわかりやすい平易な解説・重要語句を表示。

2. **全漢字ルビ（ふりがな）完全対応**
   - すべての漢字に `<ruby><rt>よみ</rt></ruby>` によるふりがなを配置（括弧書き排除）。
   - 文脈に沿った正確な訓読み・音読みを判定。
   - サイドバーのスライダーで文字・ルビの大きさを3段階（標準・大・特大）に切り替え可能。

3. **背景・文字色の高コントラスト固定（視認性保証）**
   - `.streamlit/config.toml` によるライトモード強制設定を同梱。
   - 画面の背景色と文字色が同化して読みづらくなる現象（端末のダークモードによる文字色の反転など）を完全に防止。

4. **受講者情報とGoogle Classroom提出連携**
   - クラス（26A / 26B）、学籍番号（例：9269999）、氏名・ニックネームの入力欄を完備。
   - 演習終了時に、得点・正答率・分野別内訳・認証コードを含む「Google Classroom提出用テキスト」を自動生成。
   - テキストコピー、提出用ファイル（.txt）のダウンロード、Google Classroomへの直接アクセスの各機能を搭載。

5. **3つの演習モード**
   - ランダム10問演習：講義の小テストや手軽なスキマ学習に最適。
   - テーマ別集中演習：8つの各節・項目を選んで弱点を重点補強。
   - 全70問総合チャレンジ：定期試験前の総まとめ。

---

## ファイル構成

- `app.py`: Streamlit Webアプリケーション本体（高コントラストCSS適用）
- `questions.json`: 全70問の練習問題データ（全漢字ルビ付き）
- `requirements.txt`: 動作に必要なPythonパッケージ定義（streamlit）
- `.streamlit/config.toml`: 背景色・文字色の固定テーマ設定ファイル（ライトモード固定）
- `README.md`: 本説明書

## GitHubへの登録とStreamlit Cloudでの公開手順

### ステップ1：GitHubリポジトリの作成
1. GitHub にログインし、右上の「＋」アイコンから「New repository」をクリックします。
2. リポジトリ名（例：`care-quiz-app`）を入力し、**Public** に設定して「Create repository」をクリックします。

### ステップ2：ファイルのアップロード
1. 本ZIPファイルを解凍します。
2. 作成したリポジトリ画面で「uploading an existing file」をクリックします。
3. 展開されたファイル・フォルダ一式（`app.py`, `questions.json`, `requirements.txt`, `.streamlit/`, `README.md`）をドラッグ＆ドロップします。
   ※`.streamlit` フォルダ内の `config.toml` も必ず一緒にアップロードしてください。
4. 画面下の「Commit changes」ボタンを押して保存します。

### ステップ3：Streamlit Community Cloudで公開
1. Streamlit Community Cloud (share.streamlit.io) にアクセスし、GitHubアカウントでサインインします。
2. 「New app」をクリックします。
3. リポジトリ名、ブランチ（main）、Main file path（`app.py`）を選択します。
4. 「Deploy!」ボタンをクリックすると、1〜2分でWebアプリの公開URLが発行されます。
